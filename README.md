# Sweets & Pookie — Our Story

An animated, cinematic scroll-driven timeline of Sweets & Pookie's story — from a Shaadi match to a Phuket proposal.

## Run it

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal (usually http://localhost:5173).

## Edit the story

- Timeline events live in [`src/timeline.js`](src/timeline.js) — change dates, titles, bodies, or add new entries.
- Styling in [`src/styles.css`](src/styles.css).
- Characters (SVG) in [`src/Characters.jsx`](src/Characters.jsx) — tweak hair, outfits, colors.
- Scrolling / layout logic in [`src/App.jsx`](src/App.jsx).

## Build

```bash
npm run build
npm run preview
```
